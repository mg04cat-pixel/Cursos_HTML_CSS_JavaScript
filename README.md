📚 **Estudos e Projetos: HTML, CSS e Java**

Bem-vindo(a) ao meu repositório de estudos! Aqui você encontrará exercícios, anotações e projetos desenvolvidos ao longo do aprendizado de HTML, CSS e Java. O objetivo deste espaço é registrar minha evolução, aplicar conceitos na prática e manter minhas consultas organizadas.

🛠️ **Tecnologias e Conteúdos**

🌐 **Front-end (HTML5 & CSS3)** 

- Estruturação de Páginas: Tags semânticas, formulários, listas e tabelas.
- Estilização: Seletores, CSS Grid, Flexbox e animações.
- Design Responsivo: Media queries e adaptação para dispositivos móveis.

☕ **Back-end / Lógica (Java)**

- Fundamentos: Variáveis, tipos de dados e operadores.
- Estruturas de Controle: Condicionais (if/else, switch) e laços de repetição (for, while).
- Orientação a Objetos (POO): Classes, objetos, herança, polimorfismo e encapsulamento.

📁 **Estrutura do Repositório**

🚀 **Como Executar os Projetos**

Páginas HTML/CSS:

Clone este repositório:

`git clone https://github.com/mg04cat-pixel/Cursos_HTML_CSS_JavaScript.git`

Navegue até a pasta correspondente ao exercício.
Abra o arquivo index.html em qualquer navegador.

Código Java:

Abra a pasta do exercício em uma IDE como IntelliJ IDEA, Eclipse ou VS Code (com extensão para Java).
Certifique-se de ter o JDK instalado (versão 17 ou superior recomendada).
Execute o arquivo .java desejado.
